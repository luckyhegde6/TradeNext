## Risks & Tradeoffs

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Subagents remain provider-blocked → Tier A features untestable | **Certain** (already observed) | Medium | D11: every workstream ships a Tier B path; design is capability-detected |
| `compaction.reserved` increase has no measurable effect | Medium | Low | Non-blocking; verify over subsequent sessions and re-tune |
| Adding pre-commit checks slows commits / breaks the hook | Low | Medium | Add advisory first, promote to blocking only after it passes on this branch |
| New rules add *more* injected text, re-inflating context | Medium | High | Register in `.agents/INDEX.md` (not injected) and re-run `check-doc-sizes.mjs` in Phase 6; budget is enforced |
| tsc baseline (46) drifts from unrelated concurrent work | Medium | Low | `--update` flag + document the baseline in the workflow |
| Over-engineering the orchestrator for a provider tier that may change | Medium | Medium | Keep the profile declarative; no new runtime code for orchestration |
