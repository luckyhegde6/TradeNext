4 · Optional Document Ingestion

Company page textareas accept pasted annual-report / concall text; normalizeDocumentText(content, maxLen = 50_000) (lib/services/document/normalize.ts, server-only, zero deps) trims, collapses whitespace, truncates with …[truncated], and returns "" when empty. Documents are appended to the prompt as secondary-unverified sections — the model must treat them as context, never as verified fact.

  • Route — POST Zod schema { force?, documents?: { annualReport?, concall? } } with ~50KB per-field cap; oversized → 400; unauth → 401; audit metadata gains hasDocuments.
  • UI — textareas in CompanyIntelligence.tsx; document chip shown when provided.
  • ⚠ Documents are secondary — missing data is still reported in dataGaps, never fabricated from the pasted text.
