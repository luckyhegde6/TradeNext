TradeNext — Closed IPOs with Current Prices + IPO Analysis TTL Cleanup

Closed IPOs move out of the main IPO table into a collapsible "Recently Closed IPOs" section enriched with current prices + gain/loss % (new GET /api/recommendations/ipos/closed, 1h memory cache). In parallel, a TTL cleanup task (cleanStaleIpoAnalysisRows, 90-day) prunes stale ipo_analysis rows from market_cache on every market-sync run.

v3.15.0 IPO tab enhancement closed rows leave main table 30-day window 1h closed-IPOs cache 90-day TTL cleanup

1 · The Problems

SurfaceIssue
IposTab main table✕ Closed IPOs shared the main table with Active/Forthcoming rows — no current-price context, cluttered the actionable view.
IPO analysis cache✕ market_cache rows with dataType="ipo_analysis" accumulated forever — no expiry, unbounded growth.

2 · New GET /api/recommendations/ipos/closed

Filters getUpcomingIpoIssues() for status === "Closed" + issueEndDate within the last N days (default 30), batch-fetches current prices via getStockQuote() (dynamic import, chunked 10, Promise.allSettled), computes gainPercent vs the issue price-band low, and memory-caches the result for 1 hour (IPO_CLOSED_CACHE_TTL = 3600).

  • Price-parse chain — band low via parsePriceBandLow(issuePrice); current via lastPrice from getStockQuote; graceful fallback when a quote fails (row still returned, gain blank).

3 · IPO Analysis TTL Cleanup

NEW cleanStaleIpoAnalysisRows() in ipoAnalysisService.ts deletes MarketCache rows where dataType = "ipo_analysis" AND lastSyncedAt < 90 days ago; returns the deleted count for logging. Wired in as a non-fatal step 5 of executeMarketDataSync() and as a standalone ipo_analysis_cleanup task type; surfaced in the admin TASK_TYPES enums (cron + workers routes).

4 · IposTab — Collapsible Closed Section

  • Main table now renders Active + Forthcoming only — Closed rows are removed from it.
  • NEW collapsible "Recently Closed IPOs" section — header toggle (showClosed, default false), lazy-loaded via fetchClosedPrices() on first expand.
  • Columns: symbol, current price (₹, via formatPrice) and Gain/Loss % — green for gains, red for losses.
  • Section hidden entirely when the closed list is empty (0 rows → no section).
