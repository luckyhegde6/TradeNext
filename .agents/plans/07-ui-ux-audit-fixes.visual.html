2 · Backtest Symbol-Gate Softening

The if (!symbolRecord) → 404 gate is removed from app/api/backtest/run/route.ts. The prisma.symbol.findUnique lookup is kept ONLY to derive symbolSource ("known" vs "unlisted") for labeling; fall-through is logged via logger.warn. The existing barCount < 50 → 400 guard remains the ONLY no-data failure.
