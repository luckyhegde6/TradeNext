## Decisions & Reasoning

1. **Swing screeners = the `swing` category of the existing 117-entry Chartink registry** — NEW `lib/services/chartink-scans/swing.json` (34 templates) + `swing` category in `chartinkTemplates.ts`, run through the v3.5.6 unified runner. Reasoning: user asked for "swing trading signals"; the registry + unified runner (fresh DB rows → live Chartink → ONE shared TradingView advancedScan fallback) already solves source resilience — Chartink HTTP 419 falls to TV by design, and the 72h DB capture covers cold starts.
2. **Family segregation via keyword regex on template names, default "trend"** — momentum/breakout/trend/mean-reversion/crossover/bearish mapped from name tokens (`breakout`, `momentum`, `crossover`, `bearish`, `reversal`, `mean`, …). Reasoning: 34 screeners are noise without grouping; name tokens are the only stable family signal available offline, and an unrecognized template must still land somewhere → default family.
3. **Top-20 cap + composite rank (screenerCount + marketCap + momentum)** — Reasoning: 34 overlapping swing screeners would produce hundreds of dedup'd hits; cap keeps the tab scannable. screenerCount (consensus) weights first, marketCap (liquidity) second, momentum (raw 1d change) third. Rankings must be deterministic for tests.
4. **25-bar `daily_prices` indicator enrichment with client-safe output** — RSI14/SMA20/SMA50/EMA20/volume-trend from ONE `ROW_NUMBER() OVER (PARTITION BY ticker)` query. Reasoning: no-N+1 checklist rule; a 25-bar window is enough for short-term swing signals without heavy compute; nullable fields render "—" (local DB holds ~5 symbols — data gap, not a bug; prod 1691+).
5. **AI swing agent = NEW `lib/services/ai/swing-agent.ts`, NOT reuse of the daily recommendation-agent** — LONG→BUY / SHORT→SELL / OBSERVE→HOLD routed through `evaluateRecommendationLevels` (v3.6.3) so SELL levels stay direction-aware (target below price, stop above). Reasoning: daily agent's BUY/HOLD/SELL + confidence/target/SL schema differs from a swing LONG/SHORT/OBSERVE call; direction-aware normalization is already proven (ITC regression). Fallback = OBSERVE conf-40 price-based so the tab never bricks on a bad model run.
6. **`analyzeSwingStocks` batching: batch-5, retry×2, concurrency-3, `trackAiCall(action:"swing_analysis_batch")`** — Reasoning: mirrors the proven daily batch discipline (5-stock batches avoid free-tier context limits; concurrency 3 respects the 429-prone OpenRouter free tier). When a batch run degrades at runtime (429/unparseable), the UI shows "AI targets unavailable — screener signals only" — graceful fallback, verified by design, not a code bug.
7. **Scope-aware cache keys — `unifiedCacheKey(options)` + swing `${key}:ai|noai`** — Reasoning: the unified runner cached ALL scopes under ONE fixed key (`chartink-unified:screener-results`) so a daily-recs run and a swing run served each other's template universe; the swing service cached AI and non-AI payloads under one key so an `analyze=false` warm-up poisoned `analyze=true` reads. Keys now encode sorted templateIds/categoryId/exclusions; AI flag goes in the key, never in a shared entry. Regression test uses REAL registry ids — a fake-id first attempt produced an empty run and no cache write (test proved nothing; fixed).
8. **NSE candlestick chart buttons on Swing cards + Today's Picks cards + Markets index cards** — user-requested inline chart links to `https://charting.nseindia.com/?symbol=X-EQ` (stocks) / `?symbol=INDEX` via `openNSEChart` (`lib/charting.tsx`). Markets card button keeps `preventDefault`+`stopPropagation` + keyboard handler because the card is Link-wrapped (nested-`<a>` hydration precedent v3.7.1). Verified clicks: TITAN-EQ, SARDAEN-EQ, NIFTY%2050 — outer card link never fired.
9. **Daily run now `excludeCategoryIds:["swing"]`** — Reasoning: Today's Picks composition MUST stay unchanged; swing screeners are a separate tab/consumption path. This is a one-line exclusion, not a data-model change.
10. **Commit scope** — Commit 1 (feat, cd2b4c4): all swing code + tests + chart-button changes. Commit 2 (docs, 0692b50 [skip ci]): AGENTS.md, CHANGELOG index + versions-v3, TODO, Primer, agent-memory, Lessons #67 (cache-key scope), session-todos.
