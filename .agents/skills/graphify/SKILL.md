# graphify — Codebase Knowledge Graph

Workflow: install (`uv tool install graphifyy` / `pipx install graphifyy` → `graphify install`) → run `graphify .` → artifacts in `graphify-out/` → use `graphify query/explain` for repo questions instead of reading everything. Treat `graphify-out/` as the persisted truth for architecture questions.
