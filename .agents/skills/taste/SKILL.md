# taste — Professional Visual Taste

Apply principles of good design: generous whitespace, clear hierarchy, consistent spacing (Tailwind scale), accessible color contrast, sensible typography, restrained accent usage.

When building/reviewing UI: ask — what is the user here for? Make that action visually dominant. Avoid cramming; keep lists scannable. Test at 3 breakpoints (mobile 375, tablet, desktop) with the repo's 1440×900 desktop default.
