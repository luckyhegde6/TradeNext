# unslop — Anti-AI-Slop Writing

Principles:
- Use first-person where natural; vary sentence length (short + long).
- Avoid overused filler phrases ("In this document we will...", "It's important to note...", "delve", "unlock", "landscape").
- Use concrete examples, real numbers, active voice; cut hedging ("It's worth noting that" → state the point).
- Prefer "X is Y" over "Y" is X" constructions; drop redundant restatements.

Audit every long-form doc (`AGENTS.md`, specs, changelogs): shorten, kill dead adjectives.
