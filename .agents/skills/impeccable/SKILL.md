# impeccable — UX Polish

When asked to polish a page/site, audit: loading/empty/error states, responsive behavior (375/768/1440), dark mode, contrast, button states, and check via Playwright (route-mocked or real) for console errors and visible glitches. Fix what you find, don't restructure everything.
