# Version History v3.3

> From TradeNext version history. Index: [../CHANGELOG.md](../CHANGELOG.md). All v3.x files: [versions-v3.md](./versions-v3.md).

- **v3.3.1** — Bug Fixes: Dividends tab, AI admin, History tab, Prisma raw SQL (July 21, 2026):
  - **Dividends Tab Fix**: Fixed 500 error on `/api/dividends/calendar` and `/api/corporate-actions/combined`. Root cause: raw SQL used `trade_date` but actual DB column is `"tradeDate"` (camelCase from Prisma). Fixed in `lib/services/dividendCalendarService.ts` and `app/api/corporate-actions/combined/route.ts`.
  - **AI Admin Page Redesigned**: Replaced single "Run Test" button with 4 dedicated actions: Save Configuration, Test Connection (lightweight `directPrompt()` with DB config), Test Model (custom prompt textarea), Clear Buffer (resets in-memory ring buffer). New endpoints: `/api/admin/ai/test` (POST), `/api/admin/ai/clear-buffer` (POST).
  - **Recommendations History Tab Rewritten**: Changed from displaying run jobs to showing top 20 individual stock recommendations (deduplicated by symbol, latest wins). New API `/api/recommendations/top-stocks` with `DISTINCT ON (symbol)`, proper `@@map` table names, filter/sort/pagination.
  - **Prisma createMany Bug Fix**: Removed invalid fields `screenerCount`, `firstSeenAt`, `lastSeenAt` from `RecommendationTracker.createMany()` in `dailyRecommendationService.ts` — these fields don't exist on the Prisma model.
  - **New Lessons**: Prisma `@@map` table names vs model names, camelCase column naming in raw SQL, AI test endpoint pattern.
  - **Files Created**: `app/api/admin/ai/test/route.ts`, `app/api/admin/ai/clear-buffer/route.ts`, `app/api/recommendations/top-stocks/route.ts`
  - **Files Modified**: `app/admin/ai/page.tsx`, `app/components/recommendations/HistoryTab.tsx`, `lib/services/dailyRecommendationService.ts`, `lib/services/dividendCalendarService.ts`, `app/api/corporate-actions/combined/route.ts`

- **v3.3.0** — Phase 5: Daily Recommendations Engine + Self-Heal AI + Audit Logging (July 19, 2026):
  - **Chartink Integration**: Hybrid approach — tries Chartink's `POST /screener/process` API first, falls back to equivalent TradingView screener templates. Runs 7 specific screeners daily: Short Term Breakouts, RSI Overbought/Oversold, BOSS Scanner BTST, Bullish Momentum, Bullish Marubozu 15min, Potential Breakouts, First 15min Breakout.
  - **Deduplication Engine**: Merges results across 7 screeners, tracks screener attribution (which screeners found each stock), sorts by screenerCount (stronger signal = more screeners agree).
  - **AI Recommendation Agent**: Extends OpenRouter Agent SDK with stock analysis prompts. For each stock: BUY/HOLD/SELL recommendation, confidence score (0-100%), target price, stop loss, time horizon (short/medium/long term), key reasoning, risk factors. Processes in batches of 5 to stay within token limits.
  - **Database Schema**: 8 new Prisma models — `RecommendationTracker` (long-lived stock tracking), `DailyRecommendationRun` (daily execution records), `DailyRecommendationStock` (per-run stock entries), `RecommendationStatusHistory` (status audit trail), `RecommendationAlertSubscription` (user subscriptions), `AgentPerformanceLog` (prediction accuracy), `ScreenerRunLog` (screener execution tracking), `SystemHealthLog` (health metrics).
  - **Recommendation Service**: `lib/services/dailyRecommendationService.ts` — Orchestrates screeners → dedup → AI analysis → DB storage → Telegram broadcast. Separate `checkPerformance()` function for status tracking.
  - **Cron Jobs**: Daily recommendations at 10 AM IST (04:30 UTC), performance tracking at 3:30 PM IST (10:00 UTC). Uses existing worker engine infrastructure.
  - **Public API**: `/api/recommendations` (latest), `/api/recommendations/history` (historical), `/api/recommendations/[symbol]` (detail). No auth required for viewing.
  - **Recommendations Page**: Tabbed layout — Today's Picks (AI-analyzed stocks with cards), History (past recommendations with performance), Dividends (moved from `/dividends`), Subscribe (Telegram subscription wizard).
  - **Performance Tracking**: Separate cron job monitors active recommendations against target/stop-loss prices. Updates `RecommendationTracker` status: active → target_achieved / stop_loss_hit / expired. Creates `RecommendationStatusHistory` entries.
  - **Self-Heal AI**: Circuit breaker for AI provider failures (3 failures → OPEN, 30s cooldown → HALF_OPEN), auto-retry with exponential backoff, model fallback chain (primary → secondary → tertiary → skip AI), performance degradation detection (success rate <80% warning, <60% critical).
  - **Self-Improve AI**: Prediction accuracy tracking (win/loss/breakeven), prompt versioning with auto-adjustment triggers, self-learning feed-back loop (daily accuracy calculation, weekly pattern identification, monthly prompt review).
  - **Comprehensive Audit Logging**: Unified event stream via `UnifiedEvent` model. Tracks Telegram events (subscribe/unsubscribe/verify/command/broadcast), AI agent usage (every trigger: button/cron/API), screener triggers (each run, success/failure, duration), system health metrics. Anomaly detection rules for accuracy drops, delivery failures, provider outages.
  - **Telegram Integration**: New `/daily-recommendations` bot command. Proactive broadcast to subscribers after daily run. Status change notifications (🎯 TARGET ACHIEVED, 🛑 STOP LOSS).
  - **Navigation Restructuring**: Replaced "Dividends" link in Header with "Recommendations". Dividends moved to sub-tab under Recommendations page.
  - **Files Created**: `lib/services/chartinkService.ts`, `lib/services/dailyRecommendationService.ts`, `lib/services/ai/recommendation-agent.ts`, `lib/services/ai/circuit-breaker.ts`, `lib/services/ai/performance-monitor.ts`, `lib/services/ai/prediction-tracker.ts`, `lib/services/ai/prompt-manager.ts`, `lib/services/ai/self-learning.ts`, `lib/services/unifiedEventService.ts`, `lib/services/systemHealthService.ts`, `app/api/recommendations/route.ts`, `app/api/recommendations/history/route.ts`, `app/api/recommendations/[symbol]/route.ts`, `app/api/user/recommendations/subscribe/route.ts`, `app/api/admin/recommendations/route.ts`, `app/api/system/events/route.ts`, `app/components/recommendations/DailyPicksTab.tsx`, `app/components/recommendations/HistoryTab.tsx`, `app/components/recommendations/SubscribeTab.tsx`, `app/components/recommendations/RecommendationCard.tsx`, `.agents/skills/daily-recommendations/SKILL.md`, `.agents/skills/self-heal/SKILL.md`, `.agents/skills/audit-logging/SKILL.md`, `.agents/agents/recommendation-agent.md`
