- **v3.6.3** — Direction-Aware Target/SL Evaluation (ITC SELL Bug) + Recommendations Page Redesign (August 12, 2026):
  - **Symptom**: user reported ITC showing **SELL ₹279, Target ₹306.9, Stop Loss ₹265.05** — a BUY-style level layout on a SELL call (target ABOVE price, stop BELOW). Same API/data path as the ₹0.00-v3.5.1 issue, but the levels were non-zero and contradictory.
  - **Root cause (two compounding bugs)**: (1) `recommendation-agent.ts` `normalizeRecommendation` applied a direction-BLIND fallback (`target = price * 1.1`, `stop = price * 0.95` — `DEFAULT_TARGET_MULTIPLIER`/`DEFAULT_STOP_LOSS_MULTIPLIER`) whenever the AI returned 0/missing; when the model returned contradictory levels they passed through UNCHANGED (no validation anywhere). (2) `dailyRecommendationService.ts` `checkRecommendationPerformance` compared `currentPrice >= targetPrice → target_achieved` and `currentPrice <= stopLoss → stop_loss_hit` — correct for BUY but INVERTED for SELL (a SELL "achieves" when price FALLS to the target / "stops out" when price RISES to the stop).
  - **Fix — NEW pure evaluator** (`lib/services/recommendationLevelEvaluator.ts`): `evaluateRecommendationLevels({direction, price, targetPrice?, stopLoss?}) → {direction, targetPrice, stopLoss, valid, corrections[]}`. Invariants: BUY `target > price > stop`; SELL `target < price < stop`; HOLD tight band `target > price > stop`. Defaults (2dp), SELL = inverted via direction sign −1: BUY 1.10×/0.95×, SELL 0.90×/1.05×, HOLD 1.05×/0.95×; bounds 0.3×–3× price; `valid:false` + human-readable corrections[] whenever any level was replaced; price ≤ 0 → returns the raw input unvalidated ("price anchor" correction). Wired into `normalizeRecommendation` (replaces the blind fallback, `logger.warn` on corrections; `DEFAULT_*` constants RETAINED because `dailyRecommendationService` still imports them for placeholder trackers). Perf check now direction-aware: SELL `currentPrice <= targetPrice → target_achieved`, `currentPrice >= stopLoss → stop_loss_hit`; BUY/HOLD unchanged.
  - **Backfill** (`scripts/backfill-recommendation-levels.ts`, NEW, idempotent): scans trackers with `entryPrice > 0`, runs each through the evaluator, updates ONLY changed rows, logs old/new + corrections. LIVE persisted rows (incl. ITC) still show old levels until this runs or the next daily recs run regenerates them.
  - **UI redesign (user-requested)**: `app/recommendations/page.tsx` — horizontal tab strip → vertical **"SECTIONS" sidebar** (`<aside class="lg:w-56 shrink-0"><nav class="lg:sticky lg:top-24">`, horizontal-scroll `flex nowrap overflow-x-auto` on mobile, active tab = blue tint + dot, error state inside content column); summary cards gated to `activeTab === "picks"`; 📈 header icon. `IposTab.tsx` REWRITTEN: **Current IPOs** (`Active`, 🟢 emerald "Open Now" pill w/ pulsing dot + emerald-tinted rows `bg-emerald-500/[0.06] hover:[0.12]`) / **Upcoming** (`Forthcoming`, 🕐 amber pill) / **Recently Closed** (`Closed`, ⚪ gray pill) — fixed order, separate OPEN/CLOSE columns, section divider rows; NSE endpoint already returns all statuses (live `curl /api/recommendations/ipos?refresh=1` → `{"Active":5,"Forthcoming":1,"Closed":2}`) so this was pure UI. `RecommendationCard.tsx` — screener list COLLAPSED to `MAX_VISIBLE_SCREENERS=3` chips + "+N more", "N screeners ▼/▲" toggle (cyan when expanded). `DailyPicksTab.tsx` — grid `md:grid-cols-2 xl:grid-cols-3` (accommodates sidebar).
  - **Tests**: NEW `lib/__tests__/recommendationLevelEvaluator.test.ts` (13 — ITC regression: SELL @279 target 306.9/SL 265.05 → corrected target < 279, stop > 279 + "contradict" correction; valid BUY/SELL/HOLD accepted unchanged; zeros/missing → direction defaults; absurd 10× replaced; price ≤ 0 → raw; NaN/null/2-dp rounding) + 3 agent tests (`analyzeStocks` corrects the ITC-style SELL; valid SELL unchanged; BUY 0/0 defaults unchanged). **Full suite: 484 passed / 11 skipped / 0 failures** (was 453 → 469 w/ context then +13 evaluator +2 agent = 484). `npx tsc --noEmit` clean on touched files.
